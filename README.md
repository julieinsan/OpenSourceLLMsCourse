# Udemy Open Source LLM course

From [here](https://www.udemy.com/course/open-source-llms-uncensored-secure-ai-locally-with-rag/)

We learned about:

* system prompts
* structured prompt: response type + topic + other modifiers (length, target audience, structure, language, style, etc.
* zero-shot, one-shot, and multi-shot prompting
* role prompting
* reverse prompt engineering
* just respond with OK
* Chain of thought: think step by step
* Tree of Thoughts prompting: input -> multiple options (request response from different perspectives) -> build on top results
